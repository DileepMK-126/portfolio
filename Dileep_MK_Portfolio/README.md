## Run Locally

Open `index.html` directly in a browser, or run a simple local server from this folder:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deployment

This is a static website and can be deployed to GitHub Pages, Netlify, Vercel, or any standard web hosting service.
